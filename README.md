# Apex Burger 🍔

Apex Burger is a sleek, brand-themed website designed for a modern fast-food dining experience. This project serves as a showcase of responsive web design, focusing on clean layout, effective branding, and user-friendly navigation.

## 🚀 Features
- **Responsive Navigation:** A mobile-friendly design that adapts to various screen sizes.
- **Dynamic Menu Showcase:** An organized display of food offerings with clear visual hierarchy.
- **Location Selector:** A dedicated section to help customers find local branches.
- **Brand Identity:** A consistent visual language utilizing custom styling to enhance the "Apex" brand aesthetic.

## 🛠️ Technologies Used
- **HTML5:** Semantic structure and content organization.
- **CSS3:** Responsive layouts, custom styling, and layout positioning.
